# Eğitim örneği

Bu örnek üretim kaynağı veya uygulanmış ürün değildir.
Başlangıç spec’i ile MODIFIED/ADDED delta birlikte verilmiştir.
Tüm örnek aynı change kimliğini kullanır: recover-package-change-result.
Design açık soruları tamamlanmadan gerçek üründe apply için hazır değildir.
Dosyaları mevcut ürün spec’lerini ezmeden ayrı eğitim root’unda inceleyin.
